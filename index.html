Setup Backend Google Apps Script (GAS)

Petunjuk Singkat Penggunaan:
  1. Buat Spreadsheet Baru di Google Drive, beri nama "DB SuperApp SRT2 Pasuruan".
  2. Buka menu Ekstensi > Apps Script.
  3. Salin semua kode di bawah ini lalu tempelkan ke file Code.gs.
  4. Klik Terapkan (Deploy) > Penyerahan Baru (New Deployment). Pilih tipe Web App, setel akses ke "Anyone" (Siapa saja).
  5. Salin URL Web App yang dihasilkan, lalu masukkan pada pengaturan API di aplikasi ini.
